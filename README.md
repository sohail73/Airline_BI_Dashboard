#  SkyBI: Commercial Airline Intelligence System

**SkyBI** is a high-performance Business Intelligence and Analytics dashboard engineered to extract actionable market insights from over **300,000+ commercial flight records**. Powered by **Streamlit, Python, and MySQL**, the system bridges database architecture with interactive executive decision-making tools.

---

##  Key Features

* **Real-Time Dynamic SQL Filtering:** Fast data retrieval across 300k+ records using custom indexed SQL queries.
* **Competitor Pricing & Market Share:** Interactive Plotly charts analyzing market distribution, median price spreads, and layout impact across major airlines.
* **Product Manager Strategy:** Dynamic pricing curves analyzing advance booking trends (`Price vs Days Left`).
* **Executive Data Export:** Filtered dataset preview with instant CSV download capability.

---

## Tech Stack

* **Frontend/UI:** Streamlit, Plotly Express
* **Backend & Analytics:** Python, Pandas
* **Database:** MySQL Server (Standard Connector)
