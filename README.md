# SkyBI: Commercial Airline Intelligence System

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://airlinebidashboard-bqs3tu5u5ejfzguivvxtqg.streamlit.app/)

**SkyBI** is a high-performance Business Intelligence and Analytics dashboard engineered to extract actionable market insights from over **300,000+ commercial flight records**. Built with **Streamlit, Python, and SQLite**, the system provides real-time pricing analysis and interactive decision-making tools.

 **Live Demo:** [Click Here to View SkyBI Dashboard](https://airlinebidashboard-bqs3tu5u5ejfzguivvxtqg.streamlit.app/)

---

##  Key Features

* **Fast SQL Analytics:** Instant data retrieval across 300,000+ records powered by an optimized SQLite database engine.
* **Competitor Pricing & Market Share:** Interactive Plotly charts analyzing market distribution, median price spreads, and class impacts.
* **Pricing Strategy:** Dynamic pricing curves analyzing advance booking trends (`Price vs Days Left`).
* **Executive Data Export:** Filtered dataset preview with instant CSV download capabilities.

---

## Tech Stack

* **Frontend / Dashboard:** Streamlit, Plotly Express
* **Data Processing:** Python, Pandas
* **Database:** SQLite3 (`flights.db`)
